# Веб-интерфейс сверки

React + TypeScript + Vite. Одна страница: месяц, импорт, сверка, отчёт и помощник.
Полный запуск описан в корневом README. В Docker Nginx проксирует `/api/` в API,
`/api/agent/` — в отдельный read-only процесс агента. Адрес запросов по умолчанию
относительный; frontend не привязан к порту 8080 в браузере.

Для разработки нужны Node.js 22.12+ и работающие API (8080) и агент (8081):

```bash
npm ci
npm run dev -- --port 5173
```

Vite проксирует запросы на эти два локальных адреса. При изменённых портах
обновите `server.proxy` в `vite.config.ts`. `VITE_API_URL` можно задать для
единого внешнего шлюза; по умолчанию он не нужен.

Страница показывает configured-режим источника из `/api/source-info`,
а отчёт — свой `source_mode`. Mock явно обозначен как тестовый источник.
Изменение месяца очищает отчёт и чат. При `account_mismatch` показываются
оба ID счёта, при `amount_mismatch` — суммы. Одна запись может иметь оба отличия.
Помощник получает только результаты инструментов за выбранный месяц;
данные отправляются внешней модели после отправки вопроса.

```bash
npm test
npm run build
```
