# Веб-интерфейс сверки

React + TypeScript + Vite. Одна страница для импорта данных, сверки начислений
за выбранный месяц и вопросов к помощнику.

## Запуск

Для полного приложения используйте `docker compose` из корня репозитория по
инструкции в [README.md](../README.md). Интерфейс будет доступен на
<http://localhost:5173>, API — на <http://localhost:8080/docs>. В локальном
запуске Docker источником служит HTTP mock, а не настоящая публикация 1С.

Для разработки интерфейса отдельно нужны Node.js 22.12+ и работающий API:

```sh
cd frontend
npm ci
npm run dev -- --port 5173
```

Адрес API по умолчанию — `http://localhost:8080`; при необходимости его можно
переопределить переменной `VITE_API_URL`.

## Что делает страница

- Вызывает `POST /api/import` для импорта счетов, начислений и платежей.
- Вызывает `GET /api/reconcile?period=YYYY-MM` и показывает статус, итоги и
  расхождения по записям. Сверка ничего не исправляет в PostgreSQL.
- Отправляет вопрос и выбранный период в `POST /api/agent/chat`. Сервер читает
  результаты через разрешённые инструменты и передаёт их внешней модели для
  объяснения. Помощник не получает инструмент записи. Ответ отображается как
  Markdown, включая списки и таблицы.
- Показывает ожидание и ошибки, сбрасывает старый отчёт и сообщения чата при
  смене месяца. История чата хранится только в открытой вкладке.

`src/App.tsx` отвечает за состояние страницы, `src/api.ts` — за HTTP-запросы,
`src/types.ts` — за контракты ответов, `src/MarkdownMessage.tsx` — за отображение
ответа помощника. `src/demo.ts` сохраняет вспомогательное форматирование и
демонстрационные данные для тестов; рабочая страница использует `apiGateway`.

## Проверки

```sh
cd frontend
npm test
npm run build
```

Локальный запуск приложения и работа страницы подтверждены вручную. Это проверка
с mock-источником; интеграция с опубликованной настоящей 1С пока не подтверждена.
