# Результаты проверки

Дата: 02.10.2026. Проверены два независимых режима источника: HTTP mock и настоящая
учебная 1С 8.3.27.1508 в Linux/Docker с Apache 2.4.68.

## Автоматические проверки

| Проверка | Результат |
|---|---|
| `uv run ruff check source tests scripts` | PASS |
| `uv run pytest -q` с отдельной PostgreSQL | 43 passed |
| `uv run pytest -q` без `TEST_DATABASE_URL` | 41 passed, 2 skipped |
| `cd frontend && npm test -- --run` | 8 passed |
| `cd frontend && npm run build` | PASS |
| Сборка и запуск Compose | PASS |
| UI и чат | Итоги совпадают с JSON инструментов |

PostgreSQL-тесты создают и удаляют временные схемы только в отдельно заданной
тестовой базе. Команды запуска приведены в [README](../README.md).

## Интеграционные сценарии

| Сценарий | Результат |
|---|---|
| Восстановление конфигурации 1С из XML/BSL | PASS |
| Две загрузки фикстур в 1С | Точное совпадение ID, связей и сумм |
| Первый и повторный импорт | 2 счёта, 4 начисления, 1 платёж; без дублей |
| Сверка августа 2026 | MATCH: по 3 записи и `1140000` копеек |
| Контролируемое расхождение в тестовой PostgreSQL | MISMATCH: изменённая сумма и отсутствующая запись |
| Восстановление данных | MATCH |
| Запись под APIReader в 1С | Отклонена для всех трёх справочников |
| HTTP POST/PUT/DELETE трёх ресурсов | 9 ответов 405 |
| Запись под agent_reader в PostgreSQL | Отклонена |
| Повторный запуск контейнера 1С | PASS |
| Смешанные запросы healthcheck и приложения | Две серии по 6 циклов, все сверки MATCH |

Для валидации и сверки применены навыки из `skills/`. Источник и PostgreSQL прочитаны
отдельными read-only командами; суммы получены из результатов кода.

Контролируемые различия: `amount_mismatch` для `charge-2` (`24950`/`25050`) и
`missing_in_postgres` для `charge-3` (`990000`/`null`). Изменения вносились только
в отдельную тестовую PostgreSQL. Источник 1С оставался неизменным.

## Границы проверки

Учебная публикация предназначена для локального стенда с синтетическими данными:
порт доступен на `127.0.0.1`, подключение фиксирует пользователя APIReader.
Приложение агента отделено от импортёра и использует только `agent_reader`.

Успешный mock-прогон не считается доказательством интеграции с 1С.
Инструкции восстановления и публикации: [1С в Linux/Docker](../onec/linux/README.md).
