# Работа с репозиторием

Задача проекта — импортировать тестовые данные из read-only HTTP-источника 1С в
PostgreSQL и сверять начисления за выбранный месяц. Для вывода фактов используйте
только результаты команд и тестов; не вычисляйте суммы по тексту ответа модели.

Перед импортом или проверкой источника применяйте
[навык валидации](skills/validate-source-data/SKILL.md). Для проверки отчёта и
объяснения расхождений применяйте
[навык сверки](skills/verify-reconciliation-report/SKILL.md).

Команды `source.cli.agent_tools` доступны только для чтения. Используйте
`AGENT_DATABASE_URL` с ролью `agent_reader`; ключ импортёра агенту не передавайте.
В тестовом прогоне указывайте, что источник — mock. Не называйте этот прогон
подтверждением интеграции с настоящей 1С.

После изменения Python-кода запускайте `uv run ruff check source tests scripts` и
`uv run pytest -q`. Не добавляйте `.env`, локальную базу 1С, ключи и лицензии в Git.
